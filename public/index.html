How the model works

The model treats the runoff as a two-way race on valid votes and asks: given the polls, what range of outcomes is plausible once we admit that polls can be wrong together?

1 · Aggregate

Each poll's Flávio valid-vote share is pooled into a weighted average. Weight = recency decay × (optional) √sample size, capped at 5,000 × (optional) 1.5 for pollsters with the best recent accuracy record. By default only each pollster's latest poll counts, so a firm that publishes every few days doesn't get extra say. Where a poll reported only total votes, the valid share is computed as Flávio ÷ (Flávio + Lula).

2 · Model the uncertainty

The headline number isn't the point — the spread is. Each of 40,000 simulated elections draws a final margin from a normal distribution centered on the weighted average (plus any swing adjustment), with standard deviation set by the polling error slider. This "all polls off together" term dominates because pooled sampling error is negligible.

3 · Count

The win probability is simply the share of the 40,000 simulations each candidate wins. The distribution chart is the histogram of those draws.

Honest limits

  • Garbage in, garbage out: if the polls share a systematic bias, so will this.
  • No state-level or electoral-geography modeling — it's a national popular-vote runoff, so one number decides it.
  • Most of the Oct 24 eve-of-vote batch (Datafolha, Quaest, AtlasIntel, Nexus, Palver and others) was still unpublished at 14:00 on Oct 24; only CNT/MDA is in.
  • Pollsters that release only total votes or use different question wording aren't adjusted for house effects.
  • Normality is an approximation; real polling errors can be fat-tailed.
